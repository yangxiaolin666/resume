# 学生端接口快速使用指南

## 🚀 快速开始

### 1️⃣ 启动应用

```bash
mvn clean spring-boot:run
```

### 2️⃣ 学生登录

```bash
curl -X POST http://localhost:8081/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "20230001",
    "password": "20230001",
    "userType": "student"
  }'
```

**响应示例：**
```json
{
  "code": 200,
  "data": {
    "userId": 1,
    "username": "20230001",
    "userType": "student",
    "token": "eyJ0eXAiOiJKV1QiLCJhbGci...",
    "refreshToken": "eyJ0eXAiOiJKV1QiLCJhbGci..."
  }
}
```

保存返回的`token`，后续请求需要使用。

### 3️⃣ 完善学生信息

**最简请求示例：**
```bash
curl -X PUT http://localhost:8081/stu/completeInfo \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer {你的token}" \
  -d '{
    "age": 22,
    "gender": "男",
    "major": "计算机科学与技术"
  }'
```

**完整请求示例：**
```bash

  -H "Content-Type: application/json" \
  -H "Authorization: Bearer {你的token}" \
  -d '{
    "age": 22,
    "gender": "男",
    "nation": "汉族",
    "major": "计算机科学与技术",
    "degree": "本科",
    "graduationYear": 2025,
    "internship": 2,
    "languages": [
      {"language": "英语", "level": "六级"},
      {"language": "日语", "level": "N2"}

    "cities": ["北京", "上海"],
    "provinces": ["广东"],
    "certificates": [

    "specialities": ["Java", "Python", "MySQL"],
    "jobs": ["后端开发", "全栈开发"]

```

### 4️⃣ 上传简历

```bash
curl -X POST http://localhost:8081/stu/uploadResume \
  -H "Authorization: Bearer {你的token}" \
  -F "resumeFile=@/path/to/your/resume.pdf"
```

**Windows示例：**
```powershell
curl.exe -X POST http://localhost:8081/stu/uploadResume `
  -H "Authorization: Bearer {你的token}" `
  -F "resumeFile=@C:\Users\YourName\Desktop\resume.pdf"
```

## 📋 Postman使用

### 环境变量设置

1. 创建环境变量：
   - `baseUrl`: `http://localhost:8081`
   - `token`: 登录后自动保存

2. 登录接口Tests脚本：
```javascript
var jsonData = pm.response.json();
if (jsonData.code === 200) {
  pm.environment.set("token", jsonData.data.token);
}
```

### 完善信息请求

1. **Method**: PUT
2. **URL**: `{{baseUrl}}/stu/completeInfo`
3. **Headers**:
   - `Authorization`: `Bearer {{token}}`
   - `Content-Type`: `application/json`
4. **Body** (raw JSON):
```json
{
  "age": 22,
  "gender": "男",
  "major": "计算机科学与技术",
  "degree": "本科",
  "languages": [
    {"language": "英语", "level": "六级"}
  ],
  "specialities": ["Java", "Python"]
}
```

### 上传简历请求

1. **Method**: POST
2. **URL**: `{{baseUrl}}/stu/uploadResume`
3. **Headers**:
   - `Authorization`: `Bearer {{token}}`
4. **Body** (form-data):
   - Key: `resumeFile` (类型选择File)
   - Value: 选择PDF/DOC/DOCX文件

## ⚠️ 重要说明

### 不允许修改的字段

以下字段**不能**通过此接口修改：
- ❌ 学号 (stuId)
- ❌ 姓名 (name)
- ❌ 学生ID (id)

即使在请求中包含这些字段，后端也会自动忽略。

### 文件上传限制

- **最大大小**: 10MB
- **支持格式**: PDF (.pdf), Word (.doc, .docx)
- **存储位置**: `uploads/resume/`

### 数据验证规则

1. **年龄**: 必须在 16-60 之间
2. **毕业年份**: 必须在合理范围内（当前年份-50到+10）

## 📝 常见问题

### Q1: 401 Unauthorized错误

**原因**: Token无效或已过期

**解决**: 重新登录获取新Token

### Q2: 42201 年龄超出合理范围

**原因**: 年龄不在16-60之间

**解决**: 检查age字段值

### Q3: 41301 文件大小超限

**原因**: 文件超过10MB

**解决**: 压缩文件或选择更小的文件

### Q4: 41501 文件格式不支持

**原因**: 文件不是PDF/DOC/DOCX格式

**解决**: 转换文件格式

### Q5: 文件保存失败

**原因**: 没有创建uploads目录或无写入权限

**解决**: 
```bash
mkdir -p uploads/resume
chmod 755 uploads/resume
```

## 📊 响应码说明

| 状态码 | 说明 | 处理方式 |
|--------|------|----------|
| 200 | 成功 | 继续业务流程 |
| 201 | 创建成功 | 简历上传成功 |
| 400 | 请求参数错误 | 检查请求参数 |
| 401 | 未授权 | 重新登录 |
| 404 | 学生不存在 | 检查用户数据 |
| 41301 | 文件大小超限 | 压缩文件 |
| 41501 | 文件格式不支持 | 转换格式 |
| 42201 | 年龄不合理 | 修改年龄值 |
| 42202 | 毕业年份不合法 | 修改年份值 |
| 500 | 服务器错误 | 联系管理员 |

## 💡 提示

1. **增量更新**: 只需要传入需要更新的字段即可
2. **批量操作**: 关联数据会先删除后插入
3. **事务保证**: 所有操作在一个事务中，要么全部成功要么全部失败
4. **Token有效期**: Access Token 2小时，Refresh Token 7天
