# 管理端功能使用指南

## 一、管理员账号

### 默认管理员账号
- **用户名**: `admin`
- **密码**: `admin123`
- **用户类型**: `admin`

### 初始化管理员账号
在MySQL中执行 `init_admin.sql` 脚本来创建管理员账号：
```bash
mysql -u root -p resume < init_admin.sql
```

## 二、登录获取Token

### 请求示例
```bash
POST http://localhost:8081/login
Content-Type: application/json

{
  "username": "admin",
  "password": "admin123",
  "user_type": "admin"
}
```

### 响应示例
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userId": 1,
    "username": "admin",
    "userType": "admin"
  }
}
```

**重要**：后续所有管理端接口都需要在请求头中携带Token：
```
Authorization: Bearer <token>
```

## 三、管理端八个接口

### 1. 导入学生数据
```bash
POST /admin/addStu
Content-Type: multipart/form-data
Authorization: Bearer <token>

参数:
- stuFile: Excel文件 (.xlsx格式)
```

**响应示例**：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "successCount": 10,
    "failureCount": 2,
    "errors": [
      {
        "identifier": 3,
        "reason": "学号2024081101已存在"
      },
      {
        "identifier": 5,
        "reason": "数据解析失败: 年龄格式错误"
      }
    ]
  }
}
```

### 2. 导入企业数据
```bash
POST /admin/addCom
Content-Type: multipart/form-data
Authorization: Bearer <token>

参数:
- comFile: Excel文件 (.xlsx格式)
```

### 3. 删除学生数据（支持多选）
```bash
DELETE /admin/delStu
Content-Type: application/json
Authorization: Bearer <token>

请求体:
{
  "stuIds": [1, 2, 3, 4, 5]
}
```

**响应示例**：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "successCount": 5,
    "failureCount": 0,
    "errors": []
  }
}
```

### 4. 删除企业数据（支持多选）
```bash
DELETE /admin/delCom
Content-Type: application/json
Authorization: Bearer <token>

请求体:
{
  "comIds": [1, 2, 3]
}
```

### 5. 修改学生数据
```bash
PUT /admin/updateStu
Content-Type: application/json
Authorization: Bearer <token>

请求体:
{
  "students": [
    {
      "id": 1,
      "name": "张三",
      "age": 21,
      "major": "软件工程"
    },
    {
      "id": 2,
      "name": "李四",
      "gender": "女"
    }
  ]
}
```

**说明**：
- 每个学生对象必须包含 `id` 字段
- 只需要传递需要修改的字段，未传递的字段保持不变

### 6. 修改企业数据
```bash
PUT /admin/updateCom
Content-Type: application/json
Authorization: Bearer <token>

请求体:
{
  "companies": [
    {
      "id": 1,
      "comName": "腾讯科技有限公司",
      "comRegion": "深圳市南山区"
    }
  ]
}
```

### 7. 查找学生数据
```bash
GET /admin/searchStu?username=张&page=1&pageSize=10
Authorization: Bearer <token>

参数说明:
- username: 学生姓名（模糊查询，可选）
- page: 页码，默认1
- pageSize: 每页条数，默认10
```

**响应示例**：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "list": [
      {
        "id": 1,
        "stuId": 2024081101,
        "name": "张三",
        "age": 20,
        "gender": "男",
        "nation": "汉族",
        "major": "计算机科学与技术",
        "degree": "本科生",
        "graduationYear": 2028,
        "internship": 2
      }
    ],
    "pagination": {
      "total": 100,
      "page": 1,
      "pageSize": 10
    }
  }
}
```

### 8. 查找企业数据
```bash
GET /admin/searchCom?companyName=科技&page=1&pageSize=10
Authorization: Bearer <token>

参数说明:
- companyName: 企业名称（模糊查询，可选）
- page: 页码，默认1
- pageSize: 每页条数，默认10
```

## 四、权限说明

### 身份验证流程
1. **第一层 - Token验证**：验证请求携带的Token是否有效
2. **第二层 - 管理员权限验证**：验证用户类型是否为 `admin`

### 错误响应示例

#### 未登录（401）
```json
{
  "code": 401,
  "message": "未提供Token",
  "data": null
}
```

#### Token无效（401）
```json
{
  "code": 401,
  "message": "Token无效或已过期",
  "data": null
}
```

#### 权限不足（403）
```json
{
  "code": 403,
  "message": "权限不足，需要管理员权限",
  "data": null
}
```

## 五、测试建议

### 1. Postman测试步骤
1. 导入管理员账号（执行 `init_admin.sql`）
2. 调用登录接口获取Token
3. 在Postman中设置环境变量保存Token
4. 测试八个管理端接口

### 2. Excel文件准备
参考 `Excel导入模板说明.md` 准备测试数据

### 3. 常见问题
- **问题1**: 提示"权限不足"
  - 确认使用的是管理员账号登录
  - 检查Token是否正确携带
  
- **问题2**: Excel导入失败
  - 检查文件格式是否为 `.xlsx`
  - 确认表头在第一行
  - 检查数据格式是否正确

- **问题3**: 编译错误 "StringConcatFactory cannot be resolved"
  - 确保JDK版本为17或更高
  - 执行 `mvn clean install` 重新编译

## 七、数据库表结构

### student 表
- `id`: 主键
- `stu_id`: 学号（唯一）
- `name`: 姓名
- `age`: 年龄
- `gender`: 性别
- `nation`: 民族
- `major`: 专业
- `degree`: 学位
- `graduation_year`: 毕业年份
- `internship`: 实习次数
- `user_id`: 关联用户ID

### company 表
- `id`: 主键
- `com_name`: 企业名称
- `com_region`: 所在地区
- `user_id`: 关联用户ID

### user 表
- `user_id`: 主键
- `username`: 用户名
- `password`: 密码（BCrypt加密）
- `user_type`: 用户类型（student/company/admin）
- `create_time`: 创建时间
- `update_time`: 更新时间
