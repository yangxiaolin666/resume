# 接口文档

## 错误码说明

| 错误码 | 说明             | 描述                                 | 建议处理方式                          |
| :----- | :--------------- | :----------------------------------- | :------------------------------------ |
| 200    | 成功             | 请求处理成功                         | -                                     |
| 201    | 创建成功         | 资源创建成功                         | -                                     |
| 400    | 请求参数错误     | 请求参数格式错误或缺失必填参数       | 检查请求参数格式和完整性              |
| 401    | 未授权           | 用户未登录或Token无效                | 重新登录获取有效Token                 |
| 403    | 禁止访问         | 用户权限不足                         | 检查用户角色和权限                    |
| 404    | 资源不存在       | 请求的资源不存在                     | 检查资源ID是否正确                    |
| 409    | 资源冲突         | 数据已存在或重复                     | 检查数据唯一性约束                    |
| 413    | 请求体过大       | 上传文件大小超过限制                 | 压缩文件或分批上传                    |
| 415    | 不支持的媒体类型 | 文件格式不支持                       | 使用支持的格式（.xlsx, .pdf, .doc等） |
| 422    | 数据验证失败     | 请求数据格式正确但内容不符合业务规则 | 检查数据内容和业务规则                |
| 429    | 请求过于频繁     | API调用频率超限                      | 降低请求频率或联系管理员              |
| 500    | 服务器内部错误   | 服务器处理请求时发生意外错误         | 联系系统管理员                        |
| 503    | 服务不可用       | 服务器暂时无法处理请求               | 稍后重试或联系管理员                  |

## 公共模块

### 1. 登录

#### 基本信息

- 请求路径：`/login`
- 请求方式：`POST`

#### 请求参数(body)

| 变量名    | 必填 | 数据类型 | 示例      | 备注 |
| :-------- | :--- | :------- | :-------- | :--- |
| username  | 是   | String   | 20230001  |      |
| password  | 是   | String   | 20230001  |      |
| user_type | 是   | String   | student   |      |

#### 响应数据

| 字段        | 说明       | 备注                                                         |
| ----------- | ---------- | ------------------------------------------------------------ |
| code        | 状态码     | 200：请求成功<br/>40005：用户名或密码错误<br/>40006：账号已被禁用<br/>42901：登录尝试次数过多 |
| data        | 返回的数据 | 登录成功返回用户信息和Token                                  |
| └─ token    | 访问令牌   | 用于后续接口调用的身份验证                                   |
| └─ user    | 用户信息   | 包含用户的基本信息                                           |
| └─ user.id | 用户ID     | 系统分配的用户唯一标识                                       |
| message     | 信息       | 成功/错误信息                                                |

#### 请求示例

```json
{
  "username": "20230001",
  "password": "20230001",
  "user_type": "student"
}
```

#### 响应示例

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1001,
      "username": "20230001",
      "user_type": "student"
    }
  }
}
```

### 2. 刷新Token

#### 基本信息

- 请求路径：`/refresh-token`
- 请求方式：`POST`

#### 请求头

| 参数名         | 必填 | 类型   | 说明                                 |
| :------------- | :--- | :----- | :----------------------------------- |
| Refresh-Token  | 是   | string | 刷新令牌，格式：`<refresh_token>`   |

#### 响应数据

| 字段        | 说明       | 备注                               |
| ----------- | ---------- | ---------------------------------- |
| code        | 状态码     | 200：请求成功                      |
| data        | 返回的数据 | 新的访问令牌                       |
| └─ token    | 新令牌     | 新生成的访问令牌                   |
| message     | 信息       | 成功/错误信息                      |

#### 请求示例

```json
// 请求头中包含：
// Refresh-Token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

#### 响应示例

```json
{
  "code": 200,
  "message": "Token刷新成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

## 学生端("/stu")

### 1. 完善信息

#### 基本信息

- 请求路径：`/stu/completeInfo`
- 请求方式：`PUT`

#### 请求头

| 参数名        | 必填 | 类型   | 说明                                 |
| :------------ | :--- | :----- | :----------------------------------- |

#### 请求参数 (body)

| 变量名            | 必填 | 数据类型     | 示例                 | 备注                                                         |
| :---------------- | :--- | :----------- | :------------------- | :----------------------------------------------------------- |
| age               | 否   | Integer      | `22`                 | 年龄                                                         |
| gender            | 否   | String       | `"男"`               | 性别                                                         |
| nation            | 否   | String       | `"汉族"`             | 民族                                                         |
| major             | 否   | String       | `"计算机科学"`       | 所属专业                                                     |
| degree            | 否   | String       | `"本科"`             | 学位                                                         |
| graduationYear    | 否   | Integer      | `2023`               | 毕业年份                                                     |
| internship        | 否   | Integer      | `2`                  | 实习次数                                                     |
| languages         | 否   | List<Object> | `[{"language": "英语", "level": "六级"}, {"language": "日语", "level": "N2"}]` | 语言信息对象数组，包含language和level字段                    |

| data    | object | 更新后的完整学生信息对象                                     |
