## 错误码说明

| 错误码 | 说明             | 描述                                 | 建议处理方式                          |
| :----- | :--------------- | :----------------------------------- | :------------------------------------ |
| 200    | 成功             | 请求处理成功                         | -                                     |
| 201    | 创建成功         | 资源创建成功                         | -                                     |
| 400    | 请求参数错误     | 请求参数格式错误或缺失必填参数       | 检查请求参数格式和完整性              |
| 401    | 未授权           | 用户未登录或Token无效                | 重新登录获取有效Token                 |
| 403    | 禁止访问         | 用户权限不足                         | 检查用户角色和权限                    |
| 404    | 资源不存在       | 请求的资源不存在                     | 检查资源ID是否正确                    |
| 409    | 资源冲突         | 数据已存在或重复                     | 检查数据唯一性约束                    |
| 413    | 请求体过大       | 上传文件大小超过限制                 | 压缩文件或分批上传                    |
| 415    | 不支持的媒体类型 | 文件格式不支持                       | 使用支持的格式（.xlsx, .pdf, .doc等） |
| 422    | 数据验证失败     | 请求数据格式正确但内容不符合业务规则 | 检查数据内容和业务规则                |
| 429    | 请求过于频繁     | API调用频率超限                      | 降低请求频率或联系管理员              |
| 500    | 服务器内部错误   | 服务器处理请求时发生意外错误         | 联系系统管理员                        |
| 503    | 服务不可用       | 服务器暂时无法处理请求               | 稍后重试或联系管理员                  |

## 公共模块

### 1.登录

#### 基本信息

- 请求路径：`/login`
- 请求方式：`POST`

#### 请求参数(body)

| 变量名   | 必填 | 数据类型 | 示例     | 备注 |
| :------- | :--- | :------- | :------- | :--- |
| username | 是   | String   | 20230001 |      |

| 字段    | 说明       | 备注                                                         |
