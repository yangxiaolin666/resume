## ⚠️ 注意事项

1. **地区信息格式**: 
   - `province` 和 `city` 可能包含多个值，用逗号分隔
   - 前端需要使用 `split(',')` 处理

2. **简历信息**: 
   - 只返回最新的一条简历记录
   - 如果没有上传简历，`resume` 字段为 null

3. **空数组处理**: 
   - 如果某个关联表没有数据，返回空数组 `[]`
   - 不会返回 null

4. **性能考虑**: 
   - 使用了多个 LEFT JOIN
   - 数据量大时可能影响性能
   - 建议添加适当的索引

## 🐛 常见问题

### Q1: 返回的关联数据为空？
**A**: 检查 StudentInfoMapper.xml 是否在 `resources/mapper/` 目录下

### Q2: 报错 "No such property"？
**A**: 检查 DTO 字段名与 XML 中的 `property` 是否匹配

### Q3: 地区信息显示不完整？
**A**: GROUP_CONCAT 可能被截断，执行：
```sql
SET SESSION group_concat_max_len = 1024000;
```

### Q4: 查询很慢？
**A**: 
- 检查是否有适当的索引
- 考虑添加缓存
- 检查数据量是否过大
