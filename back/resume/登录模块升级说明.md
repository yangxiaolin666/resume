# 登录模块升级说明

## 升级内容

### 1. 新增用户类型校验

**修改点：**
- `LoginDTO`添加`userType`字段（必填）
- 前端根据用户选择的身份（学生/企业/管理员）传给后端
- 后端校验用户类型是否与数据库中的一致
- 不一致返回错误码401

**请求示例：**
```json
{
  "username": "20230001",
  "password": "20230001",
  "userType": "student"
}
```

**错误响应：**
```json
{
  "code": 401,
  "message": "用户身份不匹配，请选择正确的身份登录",
  "data": null
}
```

### 2. BCrypt密码加密

**修改点：**
- 添加Spring Security Crypto依赖
- 使用BCryptPasswordEncoder验证密码
- 假设数据库中的密码已经进行了BCrypt加密
- 提供`PasswordUtil`工具类方便生成加密密码

**加密示例：**
```java
// 原始密码: 20230001
// BCrypt加密后: $2a$10$N.zmdr9k7uOCQb97.AnHYu6aJIW7kL5EhKn0bqQlY8AQQ0q6Z5g5i
```

### 3. 双Token机制

**Access Token（短期）：**
- 有效期：2小时
- 用于日常API访问
- 包含claim: tokenType = "access"

**Refresh Token（长期）：**
- 有效期：7天
- 用于刷新Access Token
- 包含claim: tokenType = "refresh"

**登录响应：**
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "userId": 1,
    "username": "20230001",
    "userType": "student",
    "token": "eyJ0eXAi...",           // Access Token
    "refreshToken": "eyJ0eXAi..."     // Refresh Token
  }
}
```

### 4. 双层拦截器实现无感刷新

**第一层：TokenRefreshInterceptor（Token刷新拦截器）**
- 执行顺序：order = 1
- 检查Access Token是否即将过期（30分钟内）
- 如果即将过期，自动生成新Token并在响应头中返回
- 响应头：`New-Token: {新的Access Token}`

**第二层：AuthInterceptor（认证拦截器）**
- 执行顺序：order = 2
- 验证Access Token是否有效
- 无效返回401错误

**拦截路径：**
- 拦截：`/com/**`, `/stu/**`, `/admin/**`
- 排除：`/login`, `/refresh-token`

### 5. 手动刷新Token接口

**接口：** `POST /refresh-token`

**请求头：**
```
Refresh-Token: {Refresh Token}
```

**响应：**
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "token": "eyJ0eXAi..."  // 新的Access Token
  }
}
```

## 使用流程

### 登录流程

1. **前端选择身份**（学生/企业/管理员）
2. **发送登录请求**
   ```json
   POST /login
   {
     "username": "20230001",
     "password": "20230001",
     "userType": "student"
   }
   ```
3. **后端验证**
   - 检查用户名是否存在
   - 校验用户类型是否匹配
   - 使用BCrypt验证密码
4. **返回双Token**
   ```json
   {
     "token": "...",        // 保存到localStorage
     "refreshToken": "..."  // 保存到localStorage（安全存储）
   }
   ```

### 访问受保护接口

1. **发送请求时携带Token**
   ```
   Authorization: Bearer {Access Token}
   ```
2. **后端拦截器自动处理**
   - TokenRefreshInterceptor：检查是否即将过期
   - AuthInterceptor：验证Token有效性
3. **前端检查响应头**
   ```javascript
   const newToken = response.headers['new-token'];
   if (newToken) {
     // 更新localStorage中的token
     localStorage.setItem('token', newToken);
   }
   ```

### 手动刷新Token

当Access Token过期时：
```javascript
POST /refresh-token
Headers: {
  "Refresh-Token": "{保存的Refresh Token}"
}
```

## 安全性提升

1. ✅ **BCrypt加密** - 防止密码泄露

## 前端集成示例

### Axios拦截器配置

```javascript
// 请求拦截器
axios.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers['Authorization'] = `Bearer ${token}`;
    }
    return config;
  },
  error => Promise.reject(error)
);

// 响应拦截器
axios.interceptors.response.use(
  response => {
    // 检查是否有新Token
    const newToken = response.headers['new-token'];
    if (newToken) {
      localStorage.setItem('token', newToken);
      console.log('Token已自动刷新');
    }
    return response;
  },
  async error => {
    const originalRequest = error.config;
    
    // Access Token过期，使用Refresh Token刷新
    if (error.response.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true;
      
      try {
        const refreshToken = localStorage.getItem('refreshToken');
        const response = await axios.post('/refresh-token', null, {
          headers: { 'Refresh-Token': refreshToken }
        });
        
        const newToken = response.data.data.token;
        localStorage.setItem('token', newToken);
        
        // 重新发送原请求
        originalRequest.headers['Authorization'] = `Bearer ${newToken}`;
        return axios(originalRequest);
      } catch (refreshError) {
        // Refresh Token也过期，跳转到登录页
        localStorage.removeItem('token');
        localStorage.removeItem('refreshToken');
        window.location.href = '/login';
        return Promise.reject(refreshError);
      }
    }
    
    return Promise.reject(error);
  }
);
```

## 注意事项

1. **数据库密码必须是BCrypt加密**
   - 使用`PasswordUtil.main()`生成加密密码
   - 或使用在线BCrypt工具

2. **Refresh Token存储**
   - 建议存储在HttpOnly Cookie中（更安全）
   - 或使用安全的存储方案

3. **Token有效期配置**
   - Access Token: 2小时（可在JwtUtil中修改）
   - Refresh Token: 7天（可在JwtUtil中修改）

4. **拦截器顺序**
   - 刷新拦截器必须在认证拦截器之前执行
