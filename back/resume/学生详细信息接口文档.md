# 学生详细信息接口文档

## 接口概述

本文档介绍企业端查询学生详细信息的接口，包括分页查询和获取所有数据的接口。

## 企业端接口("/com")

### 1. 查询学生详细信息（分页）

#### 基本信息

- 请求路径：`/detailSearch`
- 请求方式：`POST`

#### 请求头

| 参数名        | 必填 | 类型   | 说明                                 |
| :------------ | :--- | :----- | :----------------------------------- |
| Authorization | 是   | string | 用户认证令牌，格式：`Bearer <token>` |

#### 请求参数(body)

| 变量名         | 必填 | 数据类型     | 示例                                                         | 备注                                     |
| :------------- | :--- | :----------- | :----------------------------------------------------------- | :--------------------------------------- |
| id             | 否   | Integer      | 12345                                                        | 学生ID                                   |
| stuId          | 否   | Integer      | 20230001                                                     | 学号                                     |
| name           | 否   | String       | "张三"                                                       | 姓名（模糊查询）                         |
| age            | 否   | Integer      | 22                                                           | 年龄                                     |
| gender         | 否   | String       | "男"                                                         | 性别                                     |
| nation         | 否   | String       | "汉族"                                                       | 民族                                     |
| major          | 否   | String       | "计算机科学"                                                 | 所属专业（模糊查询）                     |
| degree         | 否   | String       | "本科"                                                       | 学位                                     |
| graduationYear | 否   | Integer      | 2023                                                         | 最小毕业年份                             |
| internship     | 否   | Integer      | 2                                                            | 实习次数                                 |
| languages      | 否   | List<String> | ["英语", "日语"]                                             | 语言要求（多值筛选）                     |
| languageLevel  | 否   | String       | "六级"                                                       | 语言等级筛选                             |
| cities         | 否   | List<String> | ["北京", "上海"]                                             | 城市（多值筛选）                         |
| provinces      | 否   | List<String> | ["广东", "江苏"]                                             | 省份（多值筛选）                         |
| certNames      | 否   | List<String> | ["计算机二级", "英语六级"]                                     | 证书名称（多值筛选）                     |
| certLevel      | 否   | String       | "中级"                                                       | 证书等级筛选                             |
| internshipCompany | 否 | String      | "腾讯"                                                       | 实习公司名称筛选                         |
| specialities   | 否   | List<String> | ["Java", "Python"]                                           | 专业技能（多值筛选）                     |
| pageNum        | 否   | Integer      | 1                                                            | 当前页码（默认值：1）                    |
| pageSize       | 否   | Integer      | 20                                                           | 每页大小（默认值：10）                   |

#### 响应数据

| 字段        | 说明         | 备注                                                         |
| ----------- | ------------ | ------------------------------------------------------------ |
| code        | 状态码       | 200：请求成功                                                |
| data        | 返回的数据   | PageInfo<StudentDetailDTO> 对象，包含分页信息和学生详细信息列表 |
| message     | 信息         | 成功/错误信息                                                |
| └─ total    | 总记录数     | 所有符合条件的记录总数                                       |
| └─ list     | 学生详细信息 | StudentDetailDTO 对象列表                                    |
| └─ pageNum  | 当前页码     | 当前页码                                                     |
| └─ pageSize | 每页大小     | 每页显示的记录数                                             |
| └─ pages    | 总页数       | 总页数                                                       |
| └─ size     | 当前页记录数 | 当前页实际记录数量                                           |

#### 请求示例

```json
{

  "graduationYear": 2024,
  "pageNum": 1,
  "pageSize": 10,
  "languages": ["英语"],
  "specialities": ["Java", "Python"]
}
```

## 使用说明

1. **分页查询接口**：当需要获取有限数量的数据或实现分页功能时使用 `/detailSearch` 接口。
2. **无分页接口**：当需要获取所有符合条件的数据时使用 `/allDetails` 接口，适用于导出数据等场景。
3. **查询条件**：所有查询参数均为可选，不传参表示查询所有数据。
4. **模糊查询**：name 和 major 字段支持模糊查询。
5. **多值筛选**：languages、cities、provinces、certNames、specialities 等字段支持多值筛选。
6. **认证**：所有接口都需要有效的认证Token才能访问。
