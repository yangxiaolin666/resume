### 3. 双Token机制

登录成功返回两个Token：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "userId": 1,
    "username": "20230001",
    "userType": "student",
    "token": "eyJ0eXAi...",         // Access Token (2小时)
    "refreshToken": "eyJ0eXAi..."  // Refresh Token (7天)
  }
}
```

### 4. 无感刷新Token

**自动刷新：**
- 当Access Token即将过期（30分钟内）时
- 拦截器自动生成新Token
- 在响应头中返回：`New-Token: {新Token}`

**前端处理：**
```javascript
axios.interceptors.response.use(response => {
  const newToken = response.headers['new-token'];
  if (newToken) {
    localStorage.setItem('token', newToken);
    console.log('Token已自动刷新');
  }
  return response;
});
```

**手动刷新：**
```bash
curl -X POST http://localhost:8081/refresh-token \
  -H "Refresh-Token: {你的Refresh Token}"
```

### 5. 双层拦截器

```
第1层: TokenRefreshInterceptor  → 检查Token是否即将过期
第2层: AuthInterceptor           → 验证Token是否有效
```

拦截路径：`/com/**`, `/stu/**`, `/admin/**`  
排除路径：`/login`, `/refresh-token`

## 🛠️ 前端集成

### Axios配置示例

```javascript
import axios from 'axios';

// 请求拦截器
axios.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers['Authorization'] = `Bearer ${token}`;
    }
    return config;
  }
);

// 响应拦截器
axios.interceptors.response.use(
  response => {
    // 检查是否有新Token（自动刷新）
    const newToken = response.headers['new-token'];
    if (newToken) {
      localStorage.setItem('token', newToken);
    }
    return response;
  },
  async error => {
    const originalRequest = error.config;
    
    // Token过期，使用Refresh Token刷新
    if (error.response?.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true;
      
      try {
        const refreshToken = localStorage.getItem('refreshToken');
        const response = await axios.post('/refresh-token', null, {
          headers: { 'Refresh-Token': refreshToken }
        });
        
        const newToken = response.data.data.token;
        localStorage.setItem('token', newToken);
        
        // 重新发送原请求
        originalRequest.headers['Authorization'] = `Bearer ${newToken}`;
        return axios(originalRequest);
      } catch (err) {
        // Refresh Token也过期，跳转登录
        localStorage.clear();
        window.location.href = '/login';
        return Promise.reject(err);
      }
    }
    
    return Promise.reject(error);
  }
);
```

### Vue登录组件示例

```vue
<template>
  <div>
    <select v-model="userType">
      <option value="student">学生</option>
      <option value="company">企业</option>
      <option value="admin">管理员</option>
    </select>
    <input v-model="username" placeholder="用户名" />
    <input v-model="password" type="password" placeholder="密码" />
    <button @click="login">登录</button>
  </div>
</template>

<script>
export default {
  data() {
    return {
      username: '',
      password: '',
      userType: 'student'  // 默认学生
    }
  },
  methods: {
    async login() {
      try {
        const response = await this.$http.post('/login', {
          username: this.username,
          password: this.password,
          userType: this.userType  // 传入用户类型
        });
        
        const { token, refreshToken } = response.data.data;
        
        // 保存Token
        localStorage.setItem('token', token);
        localStorage.setItem('refreshToken', refreshToken);
        
        // 跳转
        this.$router.push('/dashboard');
      } catch (error) {
        alert(error.response.data.message);
      }
    }
  }
}
</script>
```

## ⚠️ 注意事项

### 1. 数据库密码必须BCrypt加密

**错误示例：** 明文密码
```sql
-- ❌ 错误
INSERT INTO user VALUES (1, 'test', 'password', 'student', NOW(), NOW());
```

**正确示例：** BCrypt加密密码
```sql
-- ✅ 正确
INSERT INTO user VALUES (1, 'test', '$2a$10$N.zmdr9k...', 'student', NOW(), NOW());
```

**生成加密密码：**
```java
// 运行 PasswordUtil.main() 生成
System.out.println(PasswordUtil.encode("password"));
```

### 2. 前端必须传userType

所有登录请求必须包含`userType`字段，否则返回400错误。

### 3. Token存储安全

**推荐方式：**
- Access Token → localStorage（方便读取）
- Refresh Token → HttpOnly Cookie（更安全）

**当前方式：**
- 两个Token都返回在响应体中
- 前端需自行安全存储

### 4. 拦截器路径

确保前端API路径匹配拦截器配置：
- 拦截：`/com/**`, `/stu/**`, `/admin/**`
- 不拦截：`/login`, `/refresh-token`

## ❓ 常见问题

### Q1: 登录提示"用户名或密码错误"

**可能原因：**
1. 数据库密码未BCrypt加密
2. 密码输入错误

**解决方案：**
```bash
# 重新导入测试数据
mysql -u root -p resume < test_user_data.sql
```

### Q2: 提示"用户身份不匹配"

**原因：** 选择的用户类型与账号类型不一致

**解决：** 检查用户类型选择是否正确
- 20230001 → student
- company01 → company
- admin → admin

### Q3: Token刷新不生效

**检查：**
1. 前端是否正确处理响应头`New-Token`
2. 拦截器是否正确配置
3. Token是否在30分钟内过期

### Q4: Refresh Token失败

**可能原因：**
1. Refresh Token已过期（7天）
2. Refresh Token格式错误
3. 请求头名称错误（应为`Refresh-Token`）
