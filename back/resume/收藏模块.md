## POST addLike

POST /com/LikeAdd

> Body 请求参数
>
> 备注：列表形式，允许批量添加

```json
[
  {
    "comId": 0,
    "stuId": 0,
  },
  {
    "comId": 0,
    "stuId": 0,
  },
  {
    "comId": 0,
    "stuId": 0,
  }
]
```

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|comId|body|[ComLikeStu](#schemacomlikestu)| 是 |企业ID|
|stuId|body|[ComLikeStu](#schemacomlikestu)| 是 |学生ID|

> 返回示例

```json
{
  "code": null,
  "message": null,
  "data": null
}
```

## POST queryLike

POST /com/LikeQuery

> Body 请求参数

```json
{
  "com_id": 0,
  "pageNum": 1,
  "pageSize": 10
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|com_id|body|[ComLikeStuDTO](#schemacomlikestudto)| 是 | 企业ID   |
|pageNum|body|[ComLikeStuDTO](#schemacomlikestudto)| 是（默认为0） | 页数     |
|pageSize|body|[ComLikeStuDTO](#schemacomlikestudto)| 是（默认为0） | 每页大小 |

> 返回示例

> 200 Response

```json
{
  "code": null,
  "message": null,
  "data": null
}
```
