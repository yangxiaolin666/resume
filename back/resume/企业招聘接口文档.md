# 企业招聘接口文档

## 错误码说明

| 错误码 | 说明             | 描述                                 | 建议处理方式                          |
| :----- | :--------------- | :----------------------------------- | :------------------------------------ |
| 200    | 成功             | 请求处理成功                         | -                                     |
| 201    | 创建成功         | 资源创建成功                         | -                                     |
| 400    | 请求参数错误     | 请求参数格式错误或缺失必填参数       | 检查请求参数格式和完整性              |
| 401    | 未授权           | 用户未登录或Token无效                | 重新登录获取有效Token                 |
| 403    | 禁止访问         | 用户权限不足                         | 检查用户角色和权限                    |
| 404    | 资源不存在       | 请求的资源不存在                     | 检查资源ID是否正确                    |
| 409    | 资源冲突         | 数据已存在或重复                     | 检查数据唯一性约束                    |
| 413    | 请求体过大       | 上传文件大小超过限制                 | 压缩文件或分批上传                    |
| 415    | 不支持的媒体类型 | 文件格式不支持                       | 使用支持的格式（.xlsx, .pdf, .doc等） |
| 422    | 数据验证失败     | 请求数据格式正确但内容不符合业务规则 | 检查数据内容和业务规则                |
| 429    | 请求过于频繁     | API调用频率超限                      | 降低请求频率或联系管理员              |
| 500    | 服务器内部错误   | 服务器处理请求时发生意外错误         | 联系系统管理员                        |
| 503    | 服务不可用       | 服务器暂时无法处理请求               | 稍后重试或联系管理员                  |

## 公共模块

### 1. 登录

#### 基本信息

- 请求路径：`/login`
- 请求方式：`POST`

#### 请求参数(body)

| 变量名    | 必填 | 数据类型 | 示例      | 备注 |
| :-------- | :--- | :------- | :-------- | :--- |
| username  | 是   | String   | 20230001  |      |
| password  | 是   | String   | 20230001  |      |
| user_type | 是   | String   | student   |      |

#### 响应数据

| 字段        | 说明       | 备注                                                         |
| ----------- | ---------- | ------------------------------------------------------------ |
| code        | 状态码     | 200：请求成功<br/>40005：用户名或密码错误<br/>40006：账号已被禁用<br/>42901：登录尝试次数过多 |
| data        | 返回的数据 | 登录成功返回用户信息和Token                                  |
| └─ token    | 访问令牌   | 用于后续接口调用的身份验证                                   |
| └─ user    | 用户信息   | 包含用户的基本信息                                           |
| └─ user.id | 用户ID     | 系统分配的用户唯一标识                                       |
| message     | 信息       | 成功/错误信息                                                |

#### 请求示例

```json
{
  "username": "20230001",
  "password": "20230001",
  "user_type": "student"
}
```

#### 响应示例

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1001,
      "username": "20230001",
      "user_type": "student"
    }
  }
}
```

// 请求头中包含：

  }

## 企业端("/com")

### 1. 发布招聘信息

#### 基本信息

- 请求路径：`/com/jobPosting`
- 请求方式：`POST`

#### 请求头

| 参数名        | 必填 | 类型   | 说明                                 |
| :------------ | :--- | :----- | :----------------------------------- |
| Authorization | 是   | string | 用户认证令牌，格式：`Bearer <token>` |

#### 请求参数(body)

| 变量名         | 必填 | 数据类型 | 示例           | 备注                                                         |
| :------------- | :--- | :------- | :------------- | :----------------------------------------------------------- |
| title          | 是   | String   | "Java开发工程师" | 招聘职位标题，长度不超过255字符                               |
| description    | 否   | String   | "负责后端开发工作..." | 招聘职位描述，详细描述岗位职责和要求                           |
| external_link  | 否   | String   | "https://example.com/jobs/123" | 外部招聘链接，用于跳转到企业官网或其他招聘平台               |
| status         | 否   | String   | "active"       | 招聘状态，默认为"active"，可选值：active（招聘中）、inactive（已下架） |

#### 响应数据

| 字段        | 说明   | 备注                                                         |
| :--------- | :----- | :----------------------------------------------------------- |
| code       | 状态码 | 201：招聘信息发布成功<br/>40007：招聘标题为空<br/>40008：招聘描述为空<br/>40906：企业信息获取失败 |
| message    | 信息   | 成功或错误的提示信息                                         |
| data       | object | 发布后的招聘信息对象                                         |
| └─ id      | number | 系统生成的招聘信息唯一ID                                     |
| └─ com_id  | number | 关联的企业ID                                                 |
| └─ title   | string | 招聘标题                                                     |
| └─ description | string | 招聘描述                                                     |
| └─ external_link | string | 外部链接                                                     |
| └─ status  | string | 招聘状态                                                     |
| └─ created_at | string | 创建时间                                                     |
| └─ updated_at | string | 更新时间                                                     |

#### 请求示例

```json
{
  "title": "Java开发工程师",
  "description": "负责后端系统开发，参与需求分析和系统设计，编写高质量的代码，进行代码评审和单元测试。",
  "external_link": "https://example.com/jobs/123",
  "status": "active"
}
```

#### 响应示例

```json
{
  "code": 201,
  "message": "招聘信息发布成功",
  "data": {
    "id": 1,
    "com_id": 100,
    "title": "Java开发工程师",
    "description": "负责后端系统开发，参与需求分析和系统设计，编写高质量的代码，进行代码评审和单元测试。",
    "external_link": "https://example.com/jobs/123",
    "status": "active",
    "created_at": "2026-03-17 10:00:00",
    "updated_at": "2026-03-17 10:00:00"
  }
}
```

| :------------ | :--- | :----- | :----------------------------------- |

#### 请求参数(query)

| 变量名       | 必填 | 数据类型 | 示例   | 备注                                               |

| status       | 否   | String   | "active" | 招聘状态筛选，可选值：active（招聘中）、inactive（已下架） |
| pageNum      | 否   | Integer  | 1      | 当前页码（默认值：1）                               |
| pageSize     | 否   | Integer  | 10     | 每页大小（默认值：10）                              |

| 字段          | 说明       | 备注                                                         |

| code          | 状态码     | 200：请求成功                                                |

| └─ pageSize   | 每页大小   | 每页显示的记录数                                             |
| └─ pages      | 总页数     | 总页数                                                       |
| └─ size       | 当前页记录数 | 当前页实际记录数量                                           |
