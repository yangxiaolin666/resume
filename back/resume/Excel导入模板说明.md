# 管理端Excel导入模板说明

## 学生数据导入模板 (students_template.xlsx)

### Excel列结构（第一行为表头）：
| 列序号 | 字段名 | 说明 | 示例 |
|--------|--------|------|------|
| A (0) | ID | 学生主键ID | 1 |
| B (1) | 学号 | 学生学号（唯一） | 2024081101 |
| C (2) | 姓名 | 学生姓名 | 张三 |
| D (3) | 年龄 | 年龄 | 20 |
| E (4) | 性别 | 性别 | 男 |
| F (5) | 民族 | 民族 | 汉族 |
| G (6) | 专业 | 所属专业 | 计算机科学与技术 |
| H (7) | 学位 | 学位 | 本科生 |
| I (8) | 毕业年份 | 毕业年份 | 2028 |
| J (9) | 实习次数 | 实习次数 | 2 |

### 示例数据：
```
ID    学号        姓名    年龄  性别  民族    专业                学位      毕业年份  实习次数
1     2024081101  张三    20    男    汉族    计算机科学与技术    本科生    2028      2
2     2024081102  李四    21    女    汉族    软件工程            本科生    2028      1
```

## 企业数据导入模板 (companies_template.xlsx)

### Excel列结构（第一行为表头）：
| 列序号 | 字段名 | 说明 | 示例 |
|--------|--------|------|------|
| A (0) | ID | 企业主键ID | 1 |
| B (1) | 企业名称 | 企业名称（唯一） | 腾讯科技 |
| C (2) | 所在地区 | 企业所在地区 | 深圳 |

### 示例数据：
```
ID    企业名称        所在地区
1     腾讯科技        深圳
2     阿里巴巴        杭州
3     字节跳动        北京
```

## 注意事项

1. **文件格式**：仅支持 `.xlsx` 格式的Excel文件
2. **表头行**：第一行必须是表头，系统会自动跳过
3. **数据验证**：
   - 学号/企业名称不能重复
   - ID字段必须填写且唯一
   - 必填字段不能为空
4. **错误处理**：导入时会返回详细的错误信息，包括失败的行号和原因
5. **批量导入**：支持一次导入多条数据

## API接口说明

### 导入学生数据
- **接口**: POST `/admin/addStu`
- **参数**: `stuFile` (multipart/form-data)
- **需要权限**: 管理员

### 导入企业数据
- **接口**: POST `/admin/addCom`
- **参数**: `comFile` (multipart/form-data)
- **需要权限**: 管理员
