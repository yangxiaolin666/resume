### 3. ✅ 双Token机制

**实现内容：**
- **Access Token**（短期，2小时）- 用于日常API访问
- **Refresh Token**（长期，7天）- 用于刷新Access Token
- 登录成功返回两个Token

**代码位置：**
- `src/main/java/com/resume/utils/JwtUtil.java` - 双Token生成方法
- `src/main/java/com/resume/model/dto/LoginVO.java` - 添加refreshToken字段
- `src/main/java/com/resume/user/service/impl/UserServiceImpl.java` - 生成双Token

### 4. ✅ 双层拦截器实现无感刷新

**拦截器架构：**

```
请求 → TokenRefreshInterceptor (第1层) → AuthInterceptor (第2层) → Controller
        ↓                                    ↓
    检查Token是否即将过期              验证Token是否有效
    即将过期→响应头返回新Token         无效→返回401
```

**第一层：TokenRefreshInterceptor**
- Order = 1（优先执行）
- 检查Access Token是否即将过期（30分钟内）
- 自动生成新Token并在响应头返回
- 响应头：`New-Token: {新Token}`

**第二层：AuthInterceptor**
- Order = 2（后执行）
- 验证Access Token是否有效
- 无效返回401错误

**代码位置：**
- `src/main/java/com/resume/common/interceptor/TokenRefreshInterceptor.java`
- `src/main/java/com/resume/common/interceptor/AuthInterceptor.java`
- `src/main/java/com/resume/common/config/WebConfig.java` - 注册拦截器

### 5. ✅ 手动刷新Token接口

**新增接口：**
- **路径**: `POST /refresh-token`
- **请求头**: `Refresh-Token: {Refresh Token}`
- **响应**: 新的Access Token

**代码位置：**
- `src/main/java/com/resume/user/controller/LoginController.java` - refreshToken方法
- `src/main/java/com/resume/user/service/UserService.java` - 接口定义
- `src/main/java/com/resume/user/service/impl/UserServiceImpl.java` - 实现

## 技术实现细节

### 1. 用户类型校验流程

```
前端选择身份(student/company/admin)
       ↓
发送登录请求{username, password, userType}
       ↓
后端查询用户
       ↓
校验user.userType == loginDTO.userType
       ↓
匹配 → 继续验证密码
不匹配 → 返回401错误
```

### 2. BCrypt密码验证

```java
// 数据库存储（BCrypt加密）
password = "$2a$10$N.zmdr9k7uOCQb97.AnHYu6aJIW7kL5EhKn0bqQlY8AQQ0q6Z5g5i"

// 登录时验证
passwordEncoder.matches("20230001", password) // true
```

### 3. 双Token工作流程

```
登录成功
   ↓
生成Access Token (2小时) + Refresh Token (7天)
   ↓
返回给前端
   ↓
前端保存localStorage
   ↓
访问API时携带Access Token
   ↓
Access Token即将过期(30分钟内)
   ↓
拦截器自动生成新Token → 响应头返回
   ↓
前端检测到New-Token → 更新localStorage
```

### 4. 拦截器执行顺序

```
Order 1: TokenRefreshInterceptor
   ↓ (检查是否需要刷新)
Order 2: AuthInterceptor
   ↓ (验证Token有效性)
Controller
```

## 使用示例

### 前端登录流程

```javascript
// 1. 登录
const login = async (username, password, userType) => {
  const response = await axios.post('/login', {
    username,
    password,
    userType  // 根据用户选择传入
  });
  
  // 保存Token
  localStorage.setItem('token', response.data.data.token);
  localStorage.setItem('refreshToken', response.data.data.refreshToken);
};

// 2. API请求（自动刷新）
axios.interceptors.response.use(response => {
  // 检查新Token
  const newToken = response.headers['new-token'];
  if (newToken) {
    localStorage.setItem('token', newToken);
  }
  return response;
});

// 3. 手动刷新（Token过期时）
const refreshToken = async () => {
  const refreshToken = localStorage.getItem('refreshToken');
  const response = await axios.post('/refresh-token', null, {
    headers: { 'Refresh-Token': refreshToken }
  });
  localStorage.setItem('token', response.data.data.token);
};
```
